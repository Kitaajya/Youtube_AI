// JDK 1.7 HashMap.transfer() 核心循环
while (e != null) {
    next = e.next;          // ① 记下下一个
    e.next = newTable[i];   // ② 头插
    newTable[i] = e;        // ③ 更新桶头
    e = next;               // ④ 前进
}
准备就绪。两个线程将同时扩容同一个桶。

为什么会成环？

T2 先完成扩容，用头插法把 A→B 迁移成了 B→A（A.next 变 null，B.next 指向 A）。 T1 还拿着旧快照 e=A, next=B 继续走：它把 A 放到新表头后 e=B，再读 B.next 得到 A， 于是把 B 插到 A 前面并令 B.next=A，最后 e=A 又读 A.next…… 两个节点的 next 互相指向对方，环形成。之后 get() 若 key 不在环上，e=e.next 将永远循环，CPU 打满。
